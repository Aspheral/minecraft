# Aspheral Minecraft

`Aspheral/minecraft` is a monorepo for Aspheral's Minecraft projects.

Permanent projects live in top-level directories. Development branches are temporary working timelines and should be merged back into the stable `main` branch when a milestone is ready.

## Projects

- [Solar Shader](Solar-Shader/) — a cinematic, high-performance Minecraft shader project with adaptive quality goals.

Future Minecraft projects should receive their own top-level directories rather than permanent project branches.
