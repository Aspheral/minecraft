# Solar Shader GLSL Libraries

This directory is reserved for reusable GLSL include files used by Solar Shader runtime programs.

No runtime shader implementation belongs to the workspace-scaffolding milestone.

Future GLSL files added here must follow verified current Iris shaderpack conventions. Version-sensitive behavior, directives, uniforms, feature flags, or include semantics should be checked against current Iris documentation before implementation rather than assumed from memory.
