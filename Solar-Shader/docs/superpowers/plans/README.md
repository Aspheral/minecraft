# Solar Shader Implementation Plans

Approved implementation plans for Solar Shader live in this directory.

Every substantial implementation plan should:

- link to its authoritative specification,
- preserve the spec's exact project-wide constraints,
- define independently verifiable tasks,
- use explicit verification steps,
- avoid claiming runtime behavior that was not actually measured.

Substantial new systems follow the Superpowers flow:

```text
brainstorm → spec → plan → implement → verify → review
```

GitHub repository state is authoritative. Conversation recollection must never override the current files, approved specifications, plans, or commits.
