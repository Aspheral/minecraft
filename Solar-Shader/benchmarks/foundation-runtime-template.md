## Evidence interpretation

I0 may establish shaderpack discovery, enablement, Iris preprocessing/runtime compilation, world loading, dimension switching, and basic render-path smoke-test observations.

I1 requires actual rendered evidence and, for performance claims, measured runtime data with the conditions above attached.

A completed S0/S1 GitHub Actions run is not a substitute for this template.
